# VLSI Design Portfolio

**CMOS Design | Physical Layout & Verification | Verilog-A**

This repository presents two academic projects completed during my B.Sc. in Electrical and Computer Engineering at Ben-Gurion University of the Negev, as part of the *Integrated Circuits and Introduction to VLSI* course.

The projects focus on CMOS circuit design, physical implementation, and mixed-signal behavioral modeling using Cadence EDA tools.

---

## Project 1 — CMOS Design, Layout & Verification

Transistor-level CMOS design, from device characterization and schematic implementation to physical layout and verification.

**Key Activities:**
- NMOS/PMOS characterization, including I–V curves, threshold voltage, and leakage analysis.
- CMOS inverter and buffer design, transistor sizing, and propagation delay analysis.
- Physical layout implementation using Cadence Virtuoso.
- DRC, LVS, and PEX verification, including pre-layout and post-layout timing comparison.

**Tools:** Cadence Virtuoso, Cadence ADE, Calibre.

---

## Project 2 — Verilog-A Mixed-Signal Design & Simulation

Behavioral modeling and simulation of analog and mixed-signal building blocks using Verilog-A.

**Implemented Modules:**
- Sample-and-Hold (S/H)
- Analog Comparator
- 8-bit Digital-to-Analog Converter (DAC)
- DAC Reference and Counter

**Key Activities:**
- Verilog-A behavioral modeling.
- Schematic symbol and testbench development.
- Functional simulation and waveform analysis.

**Tools:** Verilog-A, Cadence Virtuoso, Cadence ADE.
